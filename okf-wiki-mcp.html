okf-wiki-mcp

Zero-dependency, 100% offline Model Context Protocol (MCP) stdio server and CLI for querying local Google OKF v0.2 and Obsidian Markdown meeting transcripts, YAML frontmatter, [[wiki-links]], and open action items inside Claude Desktop, Claude Code, Cursor, Windsurf, and OneMira.

GitHub Repository (MIT) npm Package (v1.0.3) Official MCP Registry OneMira MCP Integration Docs

Why okf-wiki-mcp?

  • Open-source local alternative to cloud meeting-memory silos (Otter.ai, Fireflies, Plaud Cloud, Granola) — your meeting notes remain plain local .md files on disk.
  • Zero npm runtime dependencies — pure Node.js >=18 standard library (node:fs, node:path), auditable in under 350 lines with zero outbound network calls.
  • Built-in security boundaries — path-traversal protection and strict --vault root confinement.
  • Compatible with any Markdown vault — works with Obsidian vaults, transcripts migrated via transcript-to-okf, or local context captured with OneMira C1.

Quick Start

# Run directly via npx (zero global install)
npx -y okf-wiki-mcp --vault ~/Documents/Meetings stats

# Or install via Homebrew
brew tap onemira-space/tap https://github.com/onemira-space/homebrew-tap
brew install okf-wiki-mcp

Connect to Claude Desktop, Claude Code & Cursor

{
  "mcpServers": {
    "okf-wiki": {
      "command": "npx",
      "args": ["-y", "okf-wiki-mcp", "--vault", "/absolute/path/to/your/vault"]
    }
  }
}

Exposed MCP Tools

ToolPurpose
okf_searchFull-text search across local Markdown transcripts and wiki notes with snippet context.
okf_action_itemsExtract open or completed Markdown checkboxes (- [ ] / - [x]) with speaker and file attribution.
okf_backlinksResolve incoming and outgoing [[wiki-links]] across topics, projects, and people profiles.
okf_read_noteRead a specific vault note safely inside the confined --vault directory.
okf_vault_statsSummarize note counts, frontmatter coverage, link density, and pending action items.
