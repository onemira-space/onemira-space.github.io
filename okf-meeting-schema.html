Google Native OKF Meeting Note Schema & Markdown Template

Why open local files matter: Cloud-bound voice recorders lock transcripts inside proprietary mobile apps and charge monthly quotas after 300 minutes. OneMira C1 (✨ Local AI · Works Standalone · 🗣️ Speaker ID · Zero Cloud) stores every transcript and Wiki topic in plain Google Native OKF Markdown so developers, consultants, researchers, and writers own their knowledge base forever.

1. Key Schema Guarantees

  • Deterministic YAML Frontmatter: Machine-parseable timestamps, device provenance, speaker roster, and wikilink topics compatible with Obsidian, Git, ripgrep, and MCP tools.
  • Works Standalone Hardware Capture: C1 captures up to 30 hours onto 32 GB onboard storage with a physical rotating aluminum turntable cue, then syncs via Bluetooth 5.4 or USB-C to OneMira Desktop.
  • Direct Agent Access via Official MCP & Mira CLI: Connect Cursor, Claude Desktop, Claude Code, ChatGPT, or Obsidian using the OneMira MCP Integration Guide and onemira-space/onemira-mcp.
  • User-Controlled Audio Retention: Keep stereo .WAV originals locally or retain compact Markdown context only, with $0/month recurring software fee.

2. Standard OKF YAML Frontmatter Specification

FieldTypePurpose
schemastringStandard identifier (google-okf-v0.2)
typeenummeeting-note | wiki-topic | speaker-profile
speakersarrayLocal Speaker ID map generated across 99 supported languages
topicsarrayDeterministic Markdown backlinks ([[Topic]]) auto-maintained by OneMira Wiki
cloud_uploadbooleanReflects Zero Cloud local transcription boundary when running offline Local AI
